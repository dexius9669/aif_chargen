# Adventures in Fantasy · генератор персонажа

Русскоязычный лист персонажа для базовой игры Дэйва Арнесона и Ричарда Снайдера (1979). Работает в браузере, данные листа хранятся локально. Лист можно скачать и открыть как JSON, распечатать или сохранить в PDF из окна печати.

## Запуск

```sh
python3 -m http.server 8000 --directory docs
```

Откройте [http://localhost:8000](http://localhost:8000). Для проверки формул выполните `node --test`.

Для GitHub Pages откройте **Settings → Pages**, в разделе **Build and deployment → Source** выберите **Deploy from a branch**, затем **main → /docs** и нажмите **Save**. Каталог `docs` содержит готовый статический сайт, все ресурсы подключены относительными путями.

## Что рассчитывает генератор

- Характеристики по к100, возраст, стартовый статус, титул, деньги и Хиты. Можно ввести результаты вручную. Есть отдельный годовой бросок естественной смерти.
- Курсы таблицы B с продолжительностью, сложностью и предварительными требованиями. Есть навыки, даваемые ремеслом, языки, прибавки к статусу, доход и опция проверок освоения.
- Таблицы C и D, казённый набор солдата, покупки по наличию, заказ, изготовление оружейником и собственные предметы. Движение, усталость и проверка Ловкости изменяются от нагрузки. Для лошади и мула учитываются поклажа, седло и вес всадника с вещами.
- Одноразовая проверка наследства из книги III. Полученное золото пополняет стартовый кошель, а предметы появляются в инвентаре с весом, свойствами и ограничениями.
- Начальный маг, запас очков магии и выбор стартовых заклинаний. В листе есть вспомогательные расчёты шанса рукопашного попадания и спасброска от магии.
- Модель создания рассчитана на человека. Магические и нечеловеческие существа из книг II–III представлены в источниках как отдельные существа со своими параметрами.

## Источники и принятые трактовки

Книга I, печатные стр. 2–7 (персонаж), 8–15 (обучение), 16–19 (снаряжение и нагрузка), 47–53 (бой и защита). Карточка, стр. 6 PDF, использована для сверки таблиц C и D. Книга II, печатные стр. 1–5 и описания заклинаний. Книга III, печатные стр. 36–44 (наследство, волшебное оружие и доспехи, амулеты и талисманы). Книга III и карточка дают параметры противников для ручного ввода в боевом расчёте.

- Хиты округляются вверх после всей формулы: `(Сила / 2 + Выносливость / 3 + Ловкость / 4) / 5`. Подставляются рабочие значения характеристик. Подготовка II даёт одну общую прибавку 2к10 к трём характеристикам согласно чтению описания курса.
- Статус 71–75 на к100 отнесён к предыдущей строке ранга 4, закрывая пробел таблицы A. Повышение выбирает достигнутый титул в своей линии. Образование берётся из стартового статуса после поправки возраста. Деньги равны десятикратному рангу плюс один год дохода от освоенных курсов, с возрастным множителем ко всей сумме. Доход с титула показан отдельно. Солдаты получают комплект и нулевой вклад дохода от курсов в стартовую сумму.
- Стартовые курсы по умолчанию осваиваются за указанный срок. Переключатель позволяет использовать общую формулу обучения и сохранять результаты попыток. Скидка лесника зависит от порядка курсов. Пример Горация на стр. 9 содержит арифметическую разницу: при расходе 150 из 156 месяцев остаётся шесть.
- Для веса между строками таблицы E используется следующая строка. Значение «не может двигаться» и предел Силы сохраняются при любом модификаторе Ловкости. Усталость показана отдельно по описанию характеристики и по боевому правилу на стр. 52.
- Курс монет по умолчанию — 1 з.м. = 10 с.м., 1 с.м. = 10 м.м.; вес кошеля по умолчанию отключён. Настройки кампании позволяют задать собственный курс, вес кошеля и поправку к средствам. Вес персонажа по умолчанию — 150 фунтов, его можно заменить вручную.
- Бурдюк берётся пустым весом в 1 фунт по книге I. В карточке OCR даёт 4 фунта; вес содержимого можно внести отдельно. Цена ножен читается в OCR как 25 з.м. Если Рефери использует другое значение, его можно внести через свой предмет.
- Для магии приняты стартовые пределы 2/3/5 заклинаний стоимостью до 2/3/4 очков соответственно. Стартовое ученичество стоит три игровых года, то есть 39 месяцев. Запас очков и предел за ход показаны отдельно.

- Наследство проверяется по возрасту в момент броска. Для диапазона 2–20 используются 2к10, для золота 20–200 — 2к10 × 10, для 10–100 — к10 × 10. Золото прибавляется после возрастного множителя. В таблице Интеллекта меча пробел 86–95 заполнен значением 4, модифицированные броски выше 100 используют последнюю строку. Неуказанный вес щита и латно-кольчужного доспеха берётся по лёгкому щиту и кирасе. Амулеты и талисманы имеют начальный вес 0. Эти значения можно изменить в инвентаре. Условные и активируемые эффекты волшебных предметов показаны в описаниях для применения за столом.
